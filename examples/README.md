# Examples

This directory contains filled usage examples for the prompt library.

Use these examples when you want to understand how to replace placeholders before pasting a prompt into Codex.

## Example Index

| Scenario | File |
|---|---|
| Empty folder to complete product | `empty-project-to-product.md` |
| Documentation to full implementation | `docs-to-full-product.md` |
| Existing app feature implementation | `existing-app-feature.md` |
| Frontend redesign | `frontend-redesign.md` |
| External API integration | `api-integration.md` |
| QA and test hardening | `qa-hardening.md` |
| Security review and hardening | `security-hardening.md` |

## How To Use

1. Open the example closest to your scenario.
2. Copy the filled placeholder block.
3. Open the matching prompt file from the repository root.
4. Replace the prompt placeholders.
5. Paste the final prompt into Codex from your project root.

If you are unsure, use `prompts/omx-super-universal-autonomous-delivery-prompt.md`.
