# Prompts

Paste-ready OMX/Codex prompts live here.

Most prompts start with `$ultragoal` and are designed to coordinate:

- durable goal ownership
- Team mode
- Ralph-style fix/verify loops
- UltraQA
- final evidence reports

## Default Prompt

Use this when you are unsure:

[`omx-super-universal-autonomous-delivery-prompt.md`](./omx-super-universal-autonomous-delivery-prompt.md)

It handles empty folders, docs-first projects, existing apps, features, integrations, redesigns, QA, security, performance, production hardening, and release readiness.
