# Changelog

All notable changes to this prompt library will be documented in this file.

This project follows a practical release-note style rather than strict semantic versioning, because the primary deliverables are prompts, templates, and workflow documents.

## v0.1.0 - Initial Prompt Library

Initial public release.

### Added

- Super-universal autonomous delivery prompt for empty folders, docs-first projects, existing codebases, features, integrations, modules, redesigns, QA, hardening, and release readiness.
- Universal product-development prompt for building full products from documentation.
- Frontend redesign prompt for applying a desired visual style to a real existing frontend.
- Feature-from-spec prompt.
- API integration prompt.
- Database/data-model prompt.
- Root-cause bugfix prompt.
- Test and QA hardening prompt.
- Security review and hardening prompt.
- Performance optimization prompt.
- Production hardening prompt.
- Release readiness prompt.
- Documentation/onboarding/runbook prompt.
- Product discovery and PRD prompt.
- Codebase audit and refactor-plan prompt.
- `AGENTS.template.md` for project-level agent contracts.
- `generate-agents-md-prompt.md` for generating project-specific `AGENTS.md` files.
- Long-form README with setup, prompt catalog, workflow map, troubleshooting, and usage guidance.
- Local SVG hero image for reliable README rendering.

### Notes

- Prompts are intentionally long-form and operational.
- Most prompts assume Codex + oh-my-codex (OMX) with `$ultragoal`, Team mode, Ralph-style fix loops, and UltraQA.
- The library is optimized for autonomous delivery with evidence, not short chat-style prompting.
