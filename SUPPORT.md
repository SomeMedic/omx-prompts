# Support

This is a prompt library, so support mostly means helping people choose, adapt, and improve prompts.

## Best Ways To Get Help

- Open an issue for prompt bugs or unclear instructions.
- Open a prompt request if you need a new workflow.
- Open a showcase issue if a prompt produced an interesting result.
- Use GitHub Discussions if enabled for broader ideas and questions.

## Before Opening An Issue

Please include:

- which prompt you used
- the project state: empty, docs-first, existing app, or maintenance task
- what you expected Codex/OMX to do
- what happened instead
- relevant prompt placeholders
- any important constraints

Do not include secrets, private credentials, paid API keys, production URLs, or sensitive user data.

## Fastest Prompt Choice

If you are unsure, start with:

```text
prompts/omx-super-universal-autonomous-delivery-prompt.md
```

It is designed to detect the project state and route itself.
