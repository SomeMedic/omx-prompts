# Showcase

This directory is for field reports and examples of real Codex/OMX runs using this prompt library.

The goal is to show what the prompts produce:

- generated project documentation
- implementation reports
- QA reports
- redesign summaries
- integration reports
- release-readiness reports

## Suggested Showcase Format

Use this template:

```md
# Showcase: Project Or Feature Name

## Prompt Used

`prompts/omx-super-universal-autonomous-delivery-prompt.md`

## Starting State

Empty folder / docs-first / existing app / maintenance task.

## Goal

What Codex/OMX was asked to do.

## Output

Files created, implementation summary, reports.

## Verification

Commands run and results.

## Lessons

What worked, what needed manual steering, and how the prompt could improve.
```

Do not include secrets, private customer data, proprietary code, or paid credentials.
