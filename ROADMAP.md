# Roadmap

This roadmap is intentionally practical. The goal is to make the repository more useful for people building real projects with Codex and OMX.

## Near Term

- Add more real-world examples for common workflows.
- Add filled prompt variants for SaaS, internal tools, dashboards, API services, and frontend redesigns.
- Add before/after showcase documents from real runs.
- Add a prompt-quality checklist for contributors.
- Add short versions of the longest prompts for lower-context runs.
- Add a guide for combining prompts across multi-day work.

## Prompt Library Expansion

Potential new prompts:

- `omx-ai-feature-prompt.md` for OpenAI/LLM-powered product features.
- `omx-mobile-app-prompt.md` for React Native or mobile-first projects.
- `omx-admin-dashboard-prompt.md` for admin/CRM/internal tools.
- `omx-design-system-prompt.md` for building reusable UI systems.
- `omx-migration-prompt.md` for data, framework, or architecture migrations.
- `omx-ci-cd-prompt.md` for GitHub Actions and deployment pipelines.
- `omx-accessibility-audit-prompt.md` for accessibility-focused review.
- `omx-observability-prompt.md` for logging, metrics, tracing, and runbooks.

## Documentation

- Add screenshots or rendered examples of generated artifacts.
- Add a glossary for OMX concepts.
- Add a "prompt selection by project state" guide.
- Add a "how to write your own prompt" guide.
- Add troubleshooting for common Codex/OMX setup problems.

## Community

- Collect user-submitted examples.
- Add issue templates for prompt requests and showcase submissions.
- Create discussions for prompt ideas and field reports.
- Tag beginner-friendly improvements as `good first issue`.
